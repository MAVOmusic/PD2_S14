# Item Review Runs

This folder is reserved for new item-image batches. Add **no more than 15 new item images per Run**.

## How each run will be handled

- Runs are independent checkpoints. The player will explicitly name the Run folder to review; I will not read ahead into other Run folders.
- I will inspect only the named Run, transcribe visible item details, and recommend what to keep, equip/switch, sell, or list for trade with confidence-tagged estimates (not live quotes unless checked).
- Prefer one item per image with its full tooltip visible. Include screenshots of current stats/gear when a proposed swap could affect character or merc stats.
- Keep original filenames when practical. If an image shows the same item as an earlier run, note that it is a duplicate or updated view.
- Folder scaffolding does not authorize reading any Run. Wait for the player's explicit instruction each time.
